## Project Overview

VenueSeat: An interactive website that allows users to choose their theatre tickets online, using HTML, CSS and Javascript. With this website, users can learn about seating layouts, check seat availability and choose their preferred seats.

This site primarily was made to practice Javascript DOM, events, arrays and objects, and browser storage.

## Features

- Interactive seating chart
- The venue consists of three seating zones (VIP, Standard and Economy).
- Description of a seat on click.
- Add and Remove Tickets
- There is an automatic ticket price calculation.
- Color representation of seat state.
- Zoom and directional controls of the map.
- Reset View
- Information of tickets is stored in localStorage.
- User Friendly on various devices.

## How to Run

1. Either clone or download the repo

2. Open the folder.

3. In your browser, open the index.html file.

4. Choose your seats and understand the various features of the seats.


## Project Structure

- index.html - Web structure

- styles.css - Design and style

- script.js - controlling map, selecting tickets, seat generation, storage - the whole functionalities
